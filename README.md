# Analisis-Sentimen-Publik-Terhadap-Redenominasi-Rupiah-Oleh-Mentri-Keuangan-Purbaya-Yudi-Sadewa

## Deskripsi

Proyek ini membahas analisis sentimen publik terhadap isu redenominasi rupiah yang berkaitan dengan pernyataan Menteri Keuangan Purbaya Yudhi Sadewa.

Analisis dilakukan untuk mengetahui bagaimana kecenderungan opini masyarakat terhadap isu redenominasi rupiah berdasarkan data teks dari media sosial.

## Tujuan

Tujuan dari proyek ini adalah:

- Mengidentifikasi sentimen publik terhadap isu redenominasi rupiah.
- Mengklasifikasikan opini masyarakat ke dalam sentimen positif, negatif, dan netral.
- Mengetahui kecenderungan respons masyarakat terhadap isu redenominasi.
- Menyajikan hasil analisis dalam bentuk visualisasi.

## Metode

Tahapan yang dilakukan dalam proyek ini meliputi:

1. Pengumpulan data teks terkait isu redenominasi rupiah.
2. Preprocessing data teks.
3. Pembersihan dan normalisasi data.
4. Analisis sentimen.
5. Klasifikasi sentimen.
6. Visualisasi hasil analisis.
7. Interpretasi hasil.

## Hasil

Hasil analisis digunakan untuk melihat distribusi dan kecenderungan sentimen publik terhadap isu redenominasi rupiah.

Output proyek meliputi:

- Distribusi sentimen publik.
- Visualisasi hasil analisis sentimen.
- Interpretasi opini masyarakat terhadap isu redenominasi rupiah.
